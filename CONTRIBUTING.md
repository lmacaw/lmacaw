# Contributing

Thanks for helping. Lmacaw is small on purpose: prefer the simplest change that works, and keep the
interface quiet.

- Open an issue before large changes so we can agree on the approach.
- Work on a branch from `develop` and open a pull request into `develop`. `main` only moves at releases.
- Run `bun run check`, `bun run test`, and `bun run test:e2e` before asking for review; CI runs the same
  checks.
- Write code, UI text, and commit messages in English. Commit messages describe what changed and why.
- New behaviour comes with a test that fails without it.

By contributing you agree that your work is licensed under the AGPL-3.0, like the rest of the project.
